# AfghanBazaar Foundation

Build Phase 1 of my university Capstone Project called:

AfghanBazaar – A Modern Cross-Border E-Commerce Platform for Afghan and Indian Products Using React.js

Use:

React.js

TypeScript

Vite

Tailwind CSS

shadcn/ui

React Router

Supabase

This is a real functional application, not a static mockup.

For this phase, ONLY build the project foundation.

Requirements:

Configure React + TypeScript + Vite.

Configure Tailwind CSS.

Configure shadcn/ui.

Configure React Router.

Connect the project to Supabase.

Create a clean folder structure for:

components

pages

layouts

hooks

services

types

lib

Create a responsive public website layout.

Create a customer dashboard layout.

Create a seller dashboard layout.

Create an admin/CRM dashboard layout.

Create navigation/sidebar components.

Create reusable buttons, cards, tables, badges, forms, dialogs, and toast notifications where appropriate.

Create loading, error, and empty-state components.

Do NOT build products, cart, orders, CRM, reports, or complex business functionality yet.

Focus only on a clean, scalable foundation.

Use a professional modern e-commerce design. Avoid excessive gradients and unnecessary animations.

Make sure the application runs correctly before finishing this phase.
